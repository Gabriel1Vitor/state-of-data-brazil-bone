# State-Of-Data-Brazil-Bone

Fork do repositório **state-of-data-brazil**  com a retirada de vários códigos referentes ao Claude e uma forma de criar um web server em Python.

```
git clone https://github.com/data-hackers-br/state-of-data-brazil-bone.git
cd state-of-data-brazil
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
flask --app index.py run
```
